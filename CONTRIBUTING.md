# Contributing to [vox-wm](https://github.com/DerjenigeUberMensch/vox-wm)

Thanks for your interest in contributing!

This project is a personal, niche window manager that has seen a lot of hard work. The code is messy, the design is questionable in places, and it’s definitely not for the faint of heart.

## What We Welcome

- Bug fixes
- Code improvements or refactoring
- Better documentation or examples
- Design critiques, including blunt honesty ("your code sucks" is okay)
- Suggestions for features or architecture changes
- Any other help you want to throw at the project

## How to Contribute

1. **Fork the repository.**  
2. **Make your changes in a feature branch.**  
3. **Test your changes thoroughly.**  
4. **Submit a pull request with a clear description of your changes.**

If you find something confusing or problematic in the code or design, don’t hesitate to open an issue or PR even if it’s just to say "I think this part sucks."


If you’re unsure about which parts of the project you can contribute to or want to check if something is worth submitting feel free to open an issue, drop a PR, or just send a message/email. No need to ask permission formally; a quick note like “can I work on xyz?” works perfectly.

## Opening Issues

If you spot bugs, want to suggest changes, or have ideas for improvements—please open an issue!  
No need to be polite or formal. Even a quick note like "change xyz" helps.  
Clear descriptions are appreciated but not required.  

Issues help keep the project moving forward, so don’t hesitate to speak up.

## Code Style

There is no strict code style enforced. Try to keep the style consistent with existing code where reasonable.


## Communication

This is a low traffic project. Pull requests and issues might take some time to get reviewed, but they are appreciated.

Thanks again for helping out this project lives and breathes because of contributions like yours!

#### Use of A.I

Most of the code wasn’t generated by AI at least, not anything I couldn’t have written myself. For tedious or repetitive stuff (like dumping a hex of all colors), I just asked AI instead of wasting my own time. A small fraction of the docs (~5%) came from AI, and, yes, this very template was AI-assisted because I was feeling lazy.

If you’re curious which parts were AI assisted, feel free to ask open an issue, drop a PR, or send a message. I’ll happily point them out (if I remember).
