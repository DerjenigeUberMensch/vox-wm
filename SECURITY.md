# Security Policy

## Supported Versions

This project does **not support any previous versions.** To receive security updates, please upgrade to the latest release.

If you wish to request a feature that was removed in a prior version, you are welcome to submit a feature request.

## Reporting a Vulnerability

To report a vulnerability, you may either:
- Open an issue in the project’s repository, or
- Email a maintainer directly for severe or urgent security concerns.

Please provide sufficient detail to help us assess and address the issue promptly.
