# char  

A `char` is a type that can hold a value range between -128 to 127.  
Generally it is used to denotate a character value in a string however may have other uses.  

# unsigned char

A `unsigned char` is a type that can hold a value range between 0 to 255.  
Generally it is used to a small integer value however may have other uses.  


For more information see [https://en.cppreference.com/w/c/keyword/char](https://en.cppreference.com/w/c/keyword/char)
