# float

A `float` is a type that can hold a value range between -3.4 x 10<sup>38</sup> to 3.4 x 10<sup>38</sup>  
Having a range of roughly 6-7 decimal digits, 1.2 x 10<sup>-38</sup> to 3.4 x 10<sup>38</sup>  
Generally it is used to denotate a character value in a string however may have other uses.  


For more information see [https://en.cppreference.com/w/c/keyword/float](https://en.cppreference.com/w/c/keyword/float)
