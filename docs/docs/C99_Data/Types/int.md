# int

A `int` is a type that can hold a value range between -2,147,483,648 to 2,147,483,647.  
Generally it is used to denotate a character value in a string however may have other uses.  

# unsigned int

A `unsigned int` is a type that can hold a value range between 0 to 4,294,967,295.  
Generally it is used to a small integer value however may have other uses.  


For more information see [https://en.cppreference.com/w/c/keyword/int](https://en.cppreference.com/w/c/keyword/int)
